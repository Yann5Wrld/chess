# Explorateur Stockfish (Android)

Échiquier d'analyse avec Stockfish : meilleur coup fléché, barre d'évaluation, 3 variantes, FEN.

L'APK est compilée automatiquement par GitHub Actions à chaque envoi de fichiers.
Elle est disponible dans **Releases** (fichier `ExplorateurStockfish.apk`).

Pour compiler en local avec Android Studio : ouvrir le dossier, puis *Build → Build APK(s)*.
